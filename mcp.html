MCP · 模型上下文协议

Model Context Protocol —— 让 AI Agent 能够安全、标准化地连接外部工具、数据和服务的开放协议。

🔧 Tools 工具

Server 暴露可执行函数，Agent 通过 tools/call 调用。类似函数调用，但跨进程、跨应用。

📦 Resources 资源

Server 暴露可读取的结构化数据，如文件、数据库记录。Agent 通过 resources/read 获取。

📋 Prompts 提示

Server 提供可复用的提示模板，如代码审查、文档生成的 Prompt 模式。

🎯 Sampling 采样

Server 可请求 Host 的模型做推理，Agent 在不同模型之间灵活切换。
