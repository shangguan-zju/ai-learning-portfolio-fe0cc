🏃 案例运算 · 深蹲膝内扣 AI 筛查

运动解剖学场景：体能测试课上，用 CNN 分析 200 名学生的深蹲视频帧，自动筛查「膝内扣」（膝关节外翻 knee valgus）——运动解剖学中，这是前交叉韧带（ACL）损伤的重要风险信号。AI 判定结果如下：
AI 判定：膝内扣AI 判定：正常合计
实际：膝内扣TP = 32FN = 8漏判 ⚠40
实际：正常FP = 12误报TN = 148160
合计44156200
1准确率 Accuracy = (32 + 148) / 200 = 90.0% —— 看起来很高？
2精确率 P = 32 / (32 + 12) = 32 / 44 ≈ 72.7% —— AI 报「膝内扣」的学生里，约 1/4 其实正常
3召回率 R = 32 / (32 + 8) = 32 / 40 = 80.0% —— 8 名真正膝内扣的学生被漏掉
4F1 = 2 × 0.727 × 0.8 / (0.727 + 0.8) ≈ 76.2%
为什么准确率会骗人：类别不平衡（正常 160 vs 膝内扣 40）时，模型就算把所有人判为「正常」，准确率也有 80% 起步。但在损伤预防场景中，漏掉 1 名膝内扣学生的代价远大于误报——这正是必须用精确率、召回率和 F1 综合评估的原因。

💻 核心代码 (PyTorch)

import torch
import torch.nn as nn

class ResCNN(nn.Module):
    def __init__(self, vocab_size, embed_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.conv1 = nn.Conv1d(embed_dim, 64, kernel_size=3, padding=1)
        self.conv2 = nn.Conv1d(64, 128, kernel_size=3, padding=1)
        self.pool = nn.MaxPool1d(2)
        self.fc1 = nn.Linear(256, 256)
        self.dropout = nn.Dropout(0.5)
        self.fc2 = nn.Linear(256, num_classes)

    def forward(self, x):
        x = self.embedding(x).transpose(1, 2)
        residual = x
        x = torch.relu(self.conv1(x)) + residual  # 残差连接
        x = self.pool(x)
        x = torch.relu(self.conv2(x))
        x = x.mean(dim=2)                # Global Avg Pool
        x = torch.relu(self.fc1(x))
        x = self.dropout(x)
        return self.fc2(x)
