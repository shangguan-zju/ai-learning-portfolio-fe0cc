混淆矩阵专项 · 例题演算

精确率 · 召回率评估

从混淆矩阵的 TP / FP / FN / TN 出发，完整演算准确率、精确率、召回率与 F1——先读矩阵，再套公式，最后对比指标背后的取舍。

🧮 先读懂混淆矩阵

混淆矩阵把「模型的判定」与「真实情况」交叉对比，得到 4 个格子。所有评估指标都从这 4 个格子算出来：

模型判为「正」模型判为「负」
实际是「正」TP真正例 · 判对了FN假负例 · 漏报 ⚠
实际是「负」FP假正例 · 误报TN真负例 · 判对了

记忆口诀：横看实际，竖看判定；对角线（TP + TN）是判对的，非对角线（FP + FN）是判错的。

📐 四个公式

准确率 ACCURACY
A = TP + TNTP + TN + FP + FN
全体样本中判对的比例
类别不平衡时会「虚高」
精确率（精准率）PRECISION
P = TPTP + FP
判为「正」的样本里
有多少是真的
召回率 RECALL
R = TPTP + FN
真实「正」例中
被找回来了多少
F1 分数
F1 = 2 × P × RP + R
P 与 R 的调和平均
任一项低都会被拉低

✏️ 例题一 · 人脸识别考勤

题目：某班 100 人，实际到课 60 人、缺勤 40 人。人脸识别系统判定 50 人「到课」、50 人「缺勤」。核对后发现：判为「到课」的 50 人中有 45 人真实到课；真实到课的 60 人中有 15 人被误判为「缺勤」。求四个指标。
判定：到课判定：缺勤合计
实际：到课TP = 45FN = 15漏记 ⚠60
实际：缺勤FP = 5误记TN = 3540
合计5050100
1准确率 A = (TP + TN) / 总数 = (45 + 35) / 100 = 80.0%
2精确率 P = TP / (TP + FP) = 45 / (45 + 5) = 45 / 50 = 90.0%
3召回率 R = TP / (TP + FN) = 45 / (45 + 15) = 45 / 60 = 75.0%
4F1 = 2 × 0.90 × 0.75 / (0.90 + 0.75) = 1.35 / 1.65 ≈ 81.8%
解析：三个「80% 上下」的数含义完全不同——准确率看全局（80%），精确率管误记（报「到课」的里面 90% 是真的），召回率管漏记（60 个真到课只找回 75%）。考勤场景每漏记 1 人都要人工补录，召回率 75% 才是短板。

✏️ 例题二 · 垃圾短信识别

题目：200 条短信中有 30 条垃圾短信。系统标出 25 条「垃圾」，其中 20 条判断正确、5 条误拦正常短信；另有 10 条垃圾短信漏网。求四个指标。
判定：垃圾判定：正常合计
实际：垃圾TP = 20FN = 10漏网 ⚠30
实际：正常FP = 5误拦TN = 165170
合计25175200
1准确率 A = (20 + 165) / 200 = 92.5%
2精确率 P = 20 / (20 + 5) = 80.0%
3召回率 R = 20 / (20 + 10) ≈ 66.7%
4F1 = 2 × 0.80 × 0.667 / (0.80 + 0.667) ≈ 1.067 / 1.467 ≈ 72.7%
解析：准确率高达 92.5%，F1 却只有 72.7% —— 类别不平衡（正常 170 vs 垃圾 30）时准确率会「虚高」：就算把所有短信都判为正常，准确率也有 85%。这种场景必须看 F1，才不会被准确率骗到。

🏥 练习 · AI 体检报告初筛

医院用 AI 初筛 1000 份体检报告，其中实际患病 100 人。系统判出 120 人「疑似患病」，其中 80 人确实患病。
先自己在草稿纸上算出准确率、精确率、召回率、F1，再点击按钮核对答案。

判定：患病判定：健康合计
实际：患病TP = 80FN = 20漏诊 ⚠100
实际：健康FP = 40误报TN = 860900
合计1208801000
1准确率 A = (80 + 860) / 1000 = 94.0%
2精确率 P = 80 / (80 + 40) = 80 / 120 ≈ 66.7%
3召回率 R = 80 / (80 + 20) = 80 / 100 = 80.0%
4F1 = 2 × 0.667 × 0.80 / (0.667 + 0.80) ≈ 1.067 / 1.467 ≈ 72.7%
解析：医疗初筛中漏诊（FN = 20）的代价远高于误报（FP = 40），所以尽管精确率只有 66.7%，80% 的召回率才是本场景最该盯住的指标——误报可以靠复查排除，漏诊没有第二次机会。
